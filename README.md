# TenzXcraft
Éditeur vidéo multipistes PySide6 + FFmpeg, inspiré des stations de montage classiques. Les dossiers `windows/`, `mac/` et `linux/` sont autonomes. Projet natif `.tzx`; ouverture compatible `.vforge`. Filtres intégrés, presets `.tzxfilter` JSON et LUT `.cube` sont fournis dans `examples/`.

TenzXcraft 🎬

Un logiciel de montage vidéo 100% local, 100% gratuit, fait par un créateur pour les créateurs.

    ⚠️ Projet en cours de développement : l'application n'est pas terminée. Des bugs et des fonctionnalités manquantes sont à prévoir. Merci de votre patience et de votre soutien !

💥 Pourquoi TenzXcraft ?

On en a marre.

Marre des grosses entreprises qui font payer des sommes astronomiques pour des logiciels de montage. Marre des abonnements mensuels, des licences hors de prix, des comptes obligatoires et des fonctionnalités verrouillées derrière un paywall.

Monter une vidéo ne devrait pas coûter un bras.

TenzXcraft est né de cette idée : proposer un logiciel de montage accessible à tout le monde, sans abonnement, sans pub, sans piège.
🤖 Vibe Coded

Ce projet est vibe codé : développé avec l'aide de l'IA, à l'instinct, en itérant au feeling plutôt qu'en suivant une architecture rigide.

Ça veut dire quoi concrètement ?

    Le code n'est pas toujours parfait ni optimisé
    Certaines parties peuvent être brouillonnes

🔒 100% local, 100% gratuit

    ✅ Gratuit : pas d'abonnement, pas de version premium, pas de filigrane

    ✅ Vie privée respectée : vos vidéos restent chez vous
    ✅ Aucun compte requis : vous téléchargez, vous lancez, vous montez

🚀 Installation

# Cloner le dépôt
git clone https://github.com/votre-pseudo/tenzxcraft.git

# Accéder au dossier
cd tenzxcraft

# Installer les dépendances
npm install

# Lancer l'application
npm start

    💡 Adaptez les commandes selon votre technologie (Python, Electron, etc.).
